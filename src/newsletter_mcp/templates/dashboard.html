Shared quota groups
Optional local limits keyed by provider/group. Keys in the same Groq organization or Gemini project must share a group. Zero means unknown, not unlimited.
Example: {"groq/default":{"rpm":20,"tpm":30000,"rpd":1000,"tpd":0,"max_concurrency":1}}. Use your actual account limits, not these illustrative numbers.

This app never emails subscribers automatically.
When a provider fails
Product Hunt or X can fall back to Tavily with labeled public sources. If Phase 3 fails, your research and draft remain saved. Adjust the model or budgets and use Retry Phase 3. Jinja is only available behind its explicit feature flag.
What multiple keys actually do
The pool distributes work across authorized credentials and tracks shared quota. Additional keys in one project or organization do not multiply its quota. Retry-After is honored. When all available quota is exhausted, the run stops safely instead of inventing output.
Cloud APIs, paid MCP services, electricity, hosting, and email distribution can still cost money.
